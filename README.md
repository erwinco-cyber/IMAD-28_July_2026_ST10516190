Party Prep

An Android app that helps you keep track of everything you need for a party. Add the items you need, and the app organizes them by category, quantity, and any extra notes — plus gives you a running total of how many items are on your list.

Features
Add items — Enter the name of each item you need for your party
Categorize — Assign each item to a category (e.g., Food, Drinks, Decorations, Supplies)
Set quantity — Specify how many of each item you need
Add comments — Include notes for any item (e.g., "get the gluten-free option")
Item count — See the total number of items on your list at a glance

Built With
Kotlin — Primary programming language
Android Studio — IDE used for development

Getting Started
Prerequisites
Android Studio (latest stable version recommended)
Android SDK
An Android device or emulator running Android

Usage
1. Open the app.
2. Tap the button to add a new item.
3. Fill in the item name, category, quantity, and any comments.
4. Save the item — it will appear in your party list along with the updated item count.
5. Edit or delete items as your plans change.
